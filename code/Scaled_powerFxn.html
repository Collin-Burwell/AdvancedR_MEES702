Exercise 3: Base R Defensive Programming, Input Validation & Dot Passing (...)

Completion requirements

Start with your refactored self-contained scaled_power() function from Exercise 2:

scaled_power <- function(x, power = 2, scale = 10) {
  pow_res <- x^power
  final_res <- pow_res * scale
  return(final_res)
}

  1. Add Input Validation & Execution Halting (stop):

    • Insert if statements at the top of your function body to validate incoming arguments:
    • Check that x is numeric (is.numeric(x)). If not, issue stop("Input 'x' must be numeric.", call. = FALSE).
    • Check that power and scale are single numeric values (is.numeric() and length() == 1).
    • Test your validation by calling scaled_power(x = "three"). Confirm that execution halts immediately.

  2. Restrict String Arguments (match.arg):

    • Add a method parameter to your function header with default options: method = c("simple", "precise").
    • Add method <- match.arg(method) at the beginning of your function body.
    • Add logic: if method == "simple", round the calculated vector using round().
    • Test partial string matching with scaled_power(c(1.2, 2.7), method = "sim").
    • Test invalid input with scaled_power(c(1.2, 2.7), method = "round") and observe the automatic error message generated by match.arg().

  3. Add Conditional Plotting & Informative Messages (message):

    • Add plot = TRUE and verbose = TRUE parameters to your function header.
    • Validate that plot and verbose are single logical values (is.logical() and length() == 1).
    • If verbose = TRUE, use message() to print the chosen method and the number of elements being processed.
    • If plot = TRUE, call base plot(x, res, main = ...) inside an if block.

  4. Enable Parameter Forwarding (...):

    • Add ... to your function header signature (scaled_power <- function(x, ..., plot = TRUE)).
    • Pass ... directly into your internal plot(x, res, ...) function call.
    • Test parameter forwarding by running your function with base graphics styling parameters:
    res <- scaled_power(
x = seq(-3, 3, by = 0.5), 
power = 2, 
scale = 5, 
method = "precise",
col = "firebrick", 
pch = 19, 
type = "b"
)
    • Confirm that optional arguments pass directly into plot() without needing to be defined individually in your function signature.
